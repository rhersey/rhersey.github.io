Network Devices

🔀 Switch

Connects devices on a LAN. It uses MAC addresses to forward frames to the correct device.

Remember: a switch mainly works with MAC addresses.

🌍 Router

Connects different networks and forwards packets using IP addresses. A home router commonly connects a LAN to the Internet.

Remember: routers connect networks.

📡 Wireless Access Point

Allows wireless devices to connect to a wired network using Wi-Fi.

🖥️ Server

Provides services or resources to other computers, such as file storage, web pages, DHCP or DNS.

MAC vs IP

MAC: hardware/network-interface address used on the local network.

IP: logical address used to identify devices and route packets between networks.

Topologies

Star: devices connect to a central switch.

Bus: devices share one main cable.

Mesh: devices have multiple interconnections, providing redundancy.

Key protocols

DNS converts domain names into IP addresses.

DHCP automatically provides network configuration such as an IP address.

Use the network 192.168.1.0/24. Try entering addresses for four PCs.

Key facts

  • Switches forward frames using MAC addresses.
  • Routers forward packets between networks using IP addresses.
  • DHCP can automatically assign IP configuration.
  • DNS translates domain names to IP addresses.
  • A /24 has 8 host bits and normally 254 usable host addresses.

Discussion questions

  1. Why would a LAN need a router to access the Internet?
  2. Why does a switch need MAC addresses?
  3. What problem does DHCP solve?
  4. What would happen if DNS stopped working?
  5. Why can't the network address normally be assigned to a host?
